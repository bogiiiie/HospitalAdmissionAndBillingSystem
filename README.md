Stephen William De Jesus · Lynet Cielo · Luster Tamanu Mangaliman · Neil Jerson Manalo

A hospital admission and billing system with role-based access for **Admin** and **Hospital Staff**.  
Built using a four-project architecture: **Model**, **BusinessLogic** (Controller + Repository), **DB** (Table, View, StoredProc, PostScript), and **UI**.

## Modules
- Login & Main Menu (role-based)
- Room Management
- Patient Information Maintenance
- Patient Info Search
- Patient Room Search
- Admission
- Admission Log History (Optional)
- Treatment/Billing Breakdown
- Doctor/Nurse Assignment (Optional)
- Billing
- Discharge
- Discharge Summary
